# Echo MS Explorer — live demo

Live demo of [echo-ms-explorer](https://github.com/jessdeng/Echo-MS-Explorer),
an interactive viewer for SCIEX Echo MS acoustic ejection data.

**Click "Load demo data"** inside the app to populate it with a synthetic
60-injection run (20 wells × 3 interleaved replicates, 2 spectral groups
separated by a ~70 s acquisition gap). All the features — peak detection,
XIC inspection, multi-compound pivot table export — work on the synthetic
data without any uploads.

Source code, install instructions, and the full feature list are on
GitHub: <https://github.com/jessdeng/Echo-MS-Explorer>
